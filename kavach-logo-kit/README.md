# Kavach logo kit

## Colors
| Name  | Hex     | Use |
|-------|---------|-----|
| Ink   | #111111 | Background, cuts, illustration |
| Cream | #F7F5F0 | Shield, wordmark |
| Fold  | #D4D4D4 | Shaded wedge (dark version) |
| Fold (light) | #4A4A4A | Shaded wedge (light version) |

Backdrop accents: indigo #1d1650, violet #7b5cff, teal #3fd1bf, T-Mobile magenta #E20074, NVIDIA green #76B900.

## Type
Wordmark: Inter Display Bold, lowercase, tight tracking (-3.5%).

## Files
- logo/ — THE MAIN LOGO: shield + "kavach". Dark, light, and transparent versions
- icon/ — shield alone, for square spots (profile pics, app icon, favicon)
- extension-icons/ — drop into the extension (16/32/48/128)
- devpost/ — 3:2 gallery thumbnail
- backdrop/ — 4K night-city backdrop, with logo and clean
- svg/ — vector sources for everything

## manifest.json
"icons": { "16": "icons/icon16.png", "32": "icons/icon32.png", "48": "icons/icon48.png", "128": "icons/icon128.png" }

## Rules
- Don't recolor the shield, add gradients, glows or outlines.
- Keep clear space around the mark at least the width of the K's stem gap x2.
- Use the full logo (shield + name) wherever there's room; the shield alone only where a square is needed.
